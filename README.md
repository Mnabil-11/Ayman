# Ayman Abdullah Al-Rahbi - Civil Engineer Portfolio

A professional portfolio website for Civil Engineer Ayman Abdullah Al-Rahbi, showcasing engineering projects, skills, and experience.

## 🛠️ Tech Stack

- **HTML5** - Semantic structure
- **CSS3** - Custom design system with CSS variables
- **JavaScript** - Interactive animations and effects
- **Vercel** - Deployment and hosting

## ✨ Features

- 🌓 Light/Dark mode toggle with localStorage persistence
- 📱 Fully responsive design (mobile, tablet, desktop)
- 🎭 Scroll-triggered animations (Intersection Observer)
- 📊 Animated counters and skill progress bars
- 🖼️ Project gallery with category filters and modals
- 💬 Testimonials slider with auto-play
- 📝 Contact form with validation
- 🔝 Back-to-top button
- ✨ Cursor glow effect
- 🏔️ Parallax hero section

## 🚀 Deployment

### Deploy to Vercel

1. Install Vercel CLI:
   ```bash
   npm i -g vercel
   ```

2. Deploy:
   ```bash
   cd ayman
   vercel
   ```

3. Follow the prompts and your site will be live!

### Alternative: GitHub + Vercel

1. Push this repo to GitHub
2. Connect to [Vercel](https://vercel.com)
3. Import the repository
4. Deploy automatically

## 📝 Customization

- **Personal Info**: Edit `index.html` to update name, contact details, and content
- **Colors**: Modify CSS variables in `:root` section of `style.css`
- **Projects**: Update project data in `script.js` (`projectData` object)
- **Images**: Replace images in the `images/` directory
